# FTP服务器管理工具

一个基于Python的图形化FTP服务器管理工具，可以轻松启动、停止和管理FTP服务。

## 功能特点

- 📡 **服务器配置**
  - 自定义侦听端口（默认21）
  - 设置最大连接数
  - 配置欢迎和退出信息
  
- 👤 **账户管理**
  - FTP/SFTP 必须设置用户名和密码，不提供匿名登录
  - 自定义访问目录
  
- 🔐 **权限控制**
  - FTP/SFTP 新配置默认只读；上传、更名、删除、创建目录按账户权限勾选
  - 下载文件
  - 上传文件
  - 文件更名
  - 删除文件
  - 创建目录

- 🖥️ **友好界面**
  - 清晰的图形界面
  - 一键启动/停止服务
  - 实时显示本机IP和连接数

- 🌐 **Web 文件分享**
  - 现代化单页管理界面（明暗主题、列表/网格双视图、移动端适配）
  - 浏览、面包屑导航、按名称/大小/时间排序、实时搜索、**全局递归搜索**（搜索框回车）
  - 图片/视频/音频/PDF/文本在线预览，网格视图图片缩略图，**视频进度条拖动（Range 断点续传）**
  - 拖拽上传、多文件上传带进度和速度显示、同名自动改名
  - 新建文件夹、重命名、删除、多选 ZIP 打包下载
  - **访问密码保护** + **只读模式**（GUI 中配置）
  - Web 可留空密码并保留完整文件管理权限，适合可信内网临时分享
  - **文本快享**：网页互传文本/代码片段，生成链接任何设备打开即取
  - 路径穿越防护与文件名净化，纯内嵌资源无需外网

- 🔁 **局域网临时双向传输**
  - 一次开启发送目录和独立接收目录；另一台电脑只需浏览器
  - 发送目录仅能浏览和下载；接收目录仅能上传，不能查看或删除原有文件
  - 选择网络接口，自动分配端口并生成本次访问码
  - 可选 30 分钟至 4 小时自动关闭；结束后地址和访问码失效

- 🔗 **WebDAV 服务**
  - 把共享目录映射为"网络驱动器"，像本地磁盘一样读写
  - Windows 资源管理器、WinSCP、RaiDrive、Cyberduck 等客户端均可连接
  - 支持 WebDAV Class 1 + Class 2（LOCK/UNLOCK），兼容 Office 等软件的直接编辑
  - 账户与权限复用 FTP/SFTP 配置（下载/上传/更名/删除/创建目录）
  - 大文件分块上传、下载支持 Range 断点续传，浏览器可直接打开目录列表
  - Basic 认证 + 路径穿越防护，纯标准库实现无额外依赖

- 🔔 **托盘常驻**
  - 关闭窗口不退出，程序驻留系统托盘后台运行
  - 托盘右键菜单：显示主窗口、开关开机自启动、退出程序
  - 双击托盘图标快速打开主窗口
  - 单实例保护，重复启动时自动提示

## 安装步骤

### 1. 安装Python
确保已安装Python 3.6或更高版本

### 2. 安装依赖
```bash
pip install -r requirements.txt
```

或者直接安装：
```bash
pip install pyftpdlib psutil paramiko pystray pillow
```

> 配置说明：首次运行会自动生成 `ftp_config.json` 保存账户和端口设置。该文件包含密码，已在 `.gitignore` 中排除，请勿提交；模板可参考 `ftp_config.example.json`

## 打包为EXE

### 方法一：使用打包脚本（推荐）
双击运行 `打包为EXE.bat` 或执行：
```bash
python packtoexe.py
```

脚本会自动：
- 检查并安装PyInstaller
- 清理旧的构建文件
- 提供单文件/单目录两种打包方式

### 方法二：手动打包
```bash
# 安装PyInstaller
pip install pyinstaller

# 单文件打包（推荐）
pyinstaller --onefile --windowed --name=FTP服务器 --add-data "config_manager.py;." --add-data "tray_manager.py;." --add-data "app_icon.ico;." --icon=app_icon.ico --hidden-import pystray._win32 --hidden-import pystray._util.win32 ftp_server_gui.py

# 或单目录打包
pyinstaller --onedir --windowed --name=FTP服务器 --add-data "config_manager.py;." --add-data "tray_manager.py;." --add-data "app_icon.ico;." --icon=app_icon.ico --hidden-import pystray._win32 --hidden-import pystray._util.win32 ftp_server_gui.py
```

打包后的文件在 `dist` 目录中

## 使用方法

### 启动程序
```bash
python ftp_server_gui.py
```

后台模式启动（不显示窗口，驻留系统托盘）：
```bash
python ftp_server_gui.py --hidden
```

### 托盘常驻与开机自启动

- **关闭窗口 = 后台常驻**：点击窗口右上角 ✕ 只是隐藏窗口，服务继续在后台运行，任务栏右下角保留托盘图标
- **打开主窗口**：双击托盘图标，或右键托盘图标选择「显示主窗口」
- **开机自启动**：右键托盘图标 → 勾选「开机自启动」。该设置写入注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，开机后程序以隐藏窗口方式在托盘启动；再次点击取消勾选即关闭自启动
- **退出程序**：右键托盘图标 → 「退出程序」，会停止所有服务并移除托盘图标
- **重复启动保护**：程序已在运行时再次启动，会提示去托盘查看，不会开第二个实例

### 基本配置

1. **FTP端口**：在「服务选择」卡片中设置FTP服务的端口号（默认21，如果权限不足可以使用2121等高端口）
2. **最大连接**：设置服务器支持的最大同时连接数
3. **账户信息**：设置FTP登录用户名和密码
4. **访问目录**：选择FTP服务器的根目录
5. **权限设置**：FTP/SFTP 默认仅允许列目录和下载；确需写入时勾选对应操作。已有配置文件中明确保存的权限继续生效

SFTP 首次启动会在用户配置目录保存主机密钥，后续启动沿用同一密钥，避免客户端反复提示服务器身份变化。

### 局域网临时双向传输

在主窗口「临时双向传输」卡片中选择：

1. **对方可下载**：选择对方可以浏览和下载的文件夹。
2. **对方上传到**：选择接收文件保存位置。接收目录不会显示给对方。
3. **网络接口**：选择与对方处于同一局域网的网卡。
4. **自动关闭**：选择 30 分钟、1 小时、2 小时或 4 小时。
5. 点击「开始临时传输」，把访问地址和访问码分别发给对方；对方用浏览器打开地址并输入访问码即可。

临时传输会绑定所选网卡、使用自动分配的端口，不修改常规 FTP/Web 配置。结束时点击「结束传输」，或等待自动关闭。建议仅在可信局域网中使用；当前临时页面使用 HTTP。

### WebDAV 服务

在主窗口「服务选择」卡片中勾选「WebDAV」并设置端口（默认 5005），账户名/密码和权限与 FTP/SFTP 完全共用：

1. 点击「启动服务」后，WebDAV 地址为 `http://本机IP:5005/`
2. **WinSCP / RaiDrive / Cyberduck**：新建连接选 WebDAV，填地址、用户名、密码即可
3. **Windows 资源管理器映射网络驱动器**：受 Windows 限制较多，见下
4. 权限说明：下载对应 GET/PROPFIND；上传对应 PUT；创建目录对应 MKCOL；更名对应 COPY/MOVE；删除对应 DELETE，均按 GUI 勾选生效

**Windows 资源管理器注意事项**（其他客户端无此限制）：

- 系统 WebClient 服务默认只允许 WebDAV 走 80/443 端口；映射驱动器需把 WebDAV 端口改为 80（需管理员权限）
- 明文 HTTP 上的 Basic 认证需修改注册表 `HKLM\SYSTEM\CurrentControlSet\Services\WebClient\Parameters` 的 `BasicAuthLevel` 为 2 并重启 WebClient 服务
- WebClient 默认单文件传输上限约 50MB（`FileSizeLimitInBytes`），大文件请用 WinSCP 等客户端
- 推荐：日常使用直接用 WinSCP/RaiDrive 连接，无需以上任何调整

### Web 文件分享

启动 Web 服务后，浏览器访问界面显示的地址即可远程管理共享目录：

- **浏览**：双击/点击文件夹进入，面包屑可快速跳转；支持按名称、大小、修改时间排序
- **搜索**：输入即过滤当前目录；按回车进行全局递归搜索（跳过隐藏目录），点结果可直接预览/下载
- **上传**：点击「上传文件」选择多个文件，或直接把文件拖到页面任意位置，显示进度和速度；大文件下载支持断点续传
- **大文件**：上传和单文件下载不限制文件大小；连接空闲超过 120 秒会断开。ZIP 打包最多 100 GiB、100000 个文件，同时最多 2 个打包任务
- **预览**：点击文件名即可预览图片、视频、音频、PDF 和常见文本格式
- **管理**：新建文件夹、重命名、删除（删除需确认）、勾选多个文件后可 ZIP 打包下载
- **快享文本**：点击「📋 快享文本」粘贴文字/代码生成链接，手机或其他设备打开链接即可一键复制
- **界面**：右上角可切换列表/网格视图和明暗主题，会自动记忆偏好
- **访问密码**：在服务选择区的「Web」行填访问密码，启动后浏览器需登录才能访问（留空则免登录）
- **只读模式**：勾选后网页端只能浏览/下载/预览/搜索，上传和管理操作被禁止（前后端双重校验）
- **安全**：禁止路径穿越访问共享目录之外的文件；上传文件名自动净化；HTML/SVG 预览强制按纯文本显示，防止脚本注入；密码比对使用常量时间比较
- **注意**：访问密码与只读模式在服务启动时生效，修改后需重新启动服务
- **网卡**：FTP、SFTP、Web 监听所有 IPv4 网卡，包括虚拟网卡；防火墙规则仍可能影响可达性

### 启动服务

1. 配置完成后点击"启动服务"按钮
2. 系统会显示服务器已启动的提示
3. 在其他设备上使用FTP客户端连接到显示的IP地址和端口

### 停止服务

点击"停止服务"按钮即可关闭FTP服务器

## FTP客户端连接示例

### Windows资源管理器
在地址栏输入：
```
ftp://用户名:密码@IP地址:端口
```
例如：
```
ftp://qwe:123@192.168.1.100:21
```

### FileZilla
- 主机：IP地址
- 用户名：设置的账户名
- 密码：设置的密码
- 端口：设置的端口号

### 命令行
```bash
ftp IP地址 端口
```

## 注意事项

⚠️ **重要提示：**

1. **端口权限**：
   - Windows系统使用21端口需要管理员权限
   - 建议使用2121等高端口避免权限问题

2. **防火墙设置**：
   - 确保防火墙允许配置的端口通信
   - Windows防火墙可能需要手动添加规则

3. **目录权限**：
   - 确保访问目录有相应的读写权限
   - 建议不要使用系统敏感目录

4. **安全建议**：
   - 使用强密码
   - 仅在可信网络环境下使用
   - 定期更换密码
   - 限制必要的权限

## 常见问题

### Q: 提示端口被占用？
A: 更换其他端口号，或关闭占用该端口的程序

### Q: 无法连接到服务器？
A: 检查防火墙设置和网络连接，确保IP地址正确

### Q: 启动失败？
A: 检查是否有管理员权限（使用21端口时），或者更换高端口号

### Q: WebDAV 映射网络驱动器失败？
A: Windows 自带的 WebClient 只支持 80/443 端口且默认拒绝明文 Basic 认证；日常建议用 WinSCP/RaiDrive/Cyberduck 连接 WebDAV，不受这些限制。坚持用资源管理器的配置方法见上文「WebDAV 服务」一节
